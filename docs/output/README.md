# Report / paper build outputs

Generated by `scripts/build_research_report.py` from frozen local metrics JSON and `data/processed/figures/` PNGs.

## Reproduce

```powershell
conda activate wave_llm
cd d:\Projects\wave-prediction-mistral-tuning
python scripts\build_research_report.py
python scripts\validate_report_html.py
# optional visual QA screenshots:
python scripts\screenshot_report_qa.py
```

PDF rendering uses Playwright + system Chrome (`channel=chrome`). Use `--skip-pdf` to only write HTML/MD.

## Outputs

| File | Role |
|------|------|
| `paper.html` / `paper.pdf` | English manuscript HTML/PDF (Base64 figures) |
| `research_report.md` | Chinese research-report source (tables + figure index) |
| `report.html` / `report.pdf` | Fully self-contained Chinese report (inline CSS + Base64 images) |
