## Instruction

Review the figure captions and formatting aspects of the manuscript:

### 1. Figure Captions
- Are captions self-contained (can be understood without reading the main text)?
- Do they state what is shown, the sample size, and the key takeaway?
- Ocean Engineering style: captions should be descriptive, not interpretive
- Check for: panel labels (a), (b), etc.; units; n values; † notation

### 2. Figure References in Text
- Are all figures referenced in the main text?
- Are references sequential (Fig. 1 before Fig. 2, etc.)?
- Are the figure descriptions in the text consistent with the captions?

### 3. Formatting Consistency
- Bold/number formatting for key values (n=24, 0.688, 0.699, etc.)
- Consistent use of **n = 24** vs **n=24** vs **n = 24**
- Consistent use of † symbol throughout
- Section numbering consistency
- Reference format consistency [1] vs [1,2] etc.

### 4. SciencePlots / Figure Quality
- Are font specifications mentioned? (Times New Roman expected)
- Resolution requirements for Ocean Engineering
- Color consistency across figures
- Legend placement and readability

### 5. Tables
- Table 5.1 and 5.2 formatting
- Column alignment
- Note placement for †
- Consistent decimal places
